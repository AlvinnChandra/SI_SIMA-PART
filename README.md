# SI_SIMA-PART
Membuat SI untuk Katalog Barang Sima Part dan Sistem Orderan untuk Tracking Logistik

Struktur FrameWork Project
FrontEnd : React.js 
BackEnd  : Node.js + Express

React (Frontend)
       ↓
   HTTP / REST API
       ↓
Node.js + Express (Backend)
       ↓
   Database

Database: Menggunakan Postgre SQL
